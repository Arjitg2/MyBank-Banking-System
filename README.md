💳 Banking System - A Simple Python Application
A basic banking system built in Python with SQLite to manage user accounts and transactions. This application allows users to create accounts, log in, check balances, transfer money, and manage their profiles. It also tracks all transactions, ensuring secure management and visibility of every action performed on the account.

🔑 Key Features:
📝 User account creation: Collect personal details, set up an account, and define an initial balance.
🔐 Login system: Users can authenticate via account number and password.
💸 Transaction management: View transaction history, transfer funds between accounts, and more.
🛠️ Profile updates: Users can modify their profile details, change their password, and manage their account settings.
🗃️ SQLite database: The app stores user data and transactions securely in a local SQLite database.

🛠️ Technologies Used:
Python: Programming language for the application logic and backend.
SQLite: Lightweight database used for storing user data and transaction records.
Datetime: Used for recording timestamps of transactions.
Object-Oriented Programming (OOP): For managing the core logic of the banking system, ensuring modular and reusable code.
